Task 3 – Python Task Automation

Project Description
This project automatically organizes JPG images from one folder into another folder using Python.

Technologies Used
- Python
- os module
- shutil module
- File Handling

Features
- Automatically detects JPG images.
- Creates a destination folder.
- Moves JPG images into the destination folder.
- Displays a success message.

How to Run

1. Download or clone this repository.
2. Make sure an `images` folder exists.
3. Add JPG images inside the `images` folder.
4. Run the following command:

```bash
python organizer.py
```
